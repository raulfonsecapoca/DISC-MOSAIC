DISC - Projet MOSAIC

Digital portfolio to justify acquired competencies in the MOSAIC project.

Description of the project

This project consists in designing an infrared camera with extended depth of field for pedestrian detection in vehicles.

To achieve this, we co-designed an optical system based on germanium lenses and a phase mask, simulated in Zemax, and combined it with image reconstruction using an averaged Wiener filter. The goal was to ensure consistent image quality across a range of object distances, improving robustness and meeting strict size and optical performance constraints.
