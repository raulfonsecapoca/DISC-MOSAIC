# DISC – MOSAIC Project: Infrared Imaging System

This website was developed as part of the DISC (Dossier Individuel de Suivi des Compétences) for the **MOSAIC project**, an interdisciplinary engineering project carried out during our studies at the Institut d’Optique Graduate School.

## 🛰️ Project Overview

The goal of the MOSAIC project was to **design an infrared camera system capable of detecting pedestrians in automotive environments**, with a particular emphasis on **extending the depth of field**. This involved addressing optical, mechanical, and signal processing challenges while working within defined performance and size constraints.

To meet these goals, our group developed a **hybrid imaging system** combining:

- A **multi-lens optical system**, using **germanium lenses** and a **phase mask**, modeled and optimized in **Zemax**.
- **Computational imaging techniques**, including image reconstruction using a **Wiener filter**, to enhance image quality over a wide object distance range.

## 📂 About This DISC

This website serves as a **digital portfolio** to present and justify the competencies acquired throughout the project. It includes:

- A breakdown of competencies defined by the DISC framework.
- Personal contributions and justifications.
- Technical proofs and supporting documents (simulations, code, reports).
